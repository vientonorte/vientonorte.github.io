## 1. Teamwork.com (PSA / client work)

| Dimensión | Hallazgo |
|-----------|----------|
| **Posicionamiento** | “AI-Powered **PSA** built for **profitability**” — no “otro PM genérico” |
| **Audiencia** | Agencias, professional services, client work (5–50+), no solo software teams |
| **Promesa** | Delivery **on time + on budget** · visibilidad cliente · capacidad del equipo · **margen** |
| **Producto** | Projects + resources + time + proofs + Desk tickets + automations + **TeamworkAI** (Scout / Flo / Plan my week) |
| **IA** | Teammates con **jobs** (plan week, project health) — no feature dump de “AI features” |
| **Pricing signal** | ~£9.99–£24.99/user/mo tiers; enterprise “talk” — claridad de valor por asiento |
| **UX web** | Hero message match fuerte · nav por job (manage clients / resources / profit) · CTAs “Get started” / Learn more · poco meta-AI fluff en titles |
| **Diferenciador** | Free client seats + proofs hub + profitability widgets en scheduler |

### Implicaciones VN (Teamwork)

1. **Message match consultoría:** hablar **rentabilidad del trabajo de cliente** y “clarity in / chaos out”, no solo “UX bonito”.  
2. **Sobre-mí / Método Ro:** ya hay Flujo Mejora Continua — alinear copy a **fases con output medible** (como health de proyecto).  
3. **Path oferta / SEM:** CTA con job claro (diagnóstico → prototipo → proceso) como intake forms de Teamwork.  
4. **No copiar PSA** — VN no es Teamwork; sí copiar **claridad de job + profit language + progressive AI**.  
5. **Benchmark KPI para FO:** ¿un visitante entiende en 10s *qué gana el negocio*? (Teamwork: profit / client work).

### Gaps VN vs Teamwork

| Teamwork | VN hoy | Gap |
|----------|--------|-----|
| Profit / budget language | Más craft + método | P1 copy embudo / consultoría |
| Client portal / proofs | No aplica 1:1 | N/A |
| AI with named jobs | Skills Grok, no producto public | Parking |
| Free trial CTA | Calendar / form | OK si smoke H5 <30s |

## 2. LG.com (retail CE + soporte + diseño industrial)

| Dimensión | Hallazgo |
|-----------|----------|
| **CL home** | Title: “LG.COM Chile · Tienda oficial · Hasta 12 cuotas” — e-commerce + financiación |
| **Promesa** | Innovación de producto + **experiencia de compra** (cuotas) + vida más fácil |
| **Taxonomía** | TV/OLED, lavadoras, refrigeración, ThinQ/IA (señal fuerte “IA” en copy CL) |
| **Soporte** | `/cl/soporte` — guías, software, servicio; job “ayúdame con mi producto” |
| **Careers Design (global)** | Roles ID/Product Design: **research, consumer insights, trends, business context** (no solo UI) |
| **UX web** | Mega-site Akamai · cookie walls · JS pesado · multi-region · 403 a scrapers · mobile retail density |
| **US** | Más brand/support stack; careers en lge-careers.com |

### Implicaciones VN (LG) — entrevista + portafolio

1. **Entrevista LG:** enmarcar perfil como **sistemas de decisión + consumer/product insight + compliance/ops**, no solo pantallas.  
2. **Evidence map:** SURA wealth (regulación) · Transvip (flujos servicio) · Método Ro (mejora continua) · micro1 (AI data quality).  
3. **Jobs-to-be-done LG.com:** Discover → Configure/Buy → Support — mapear a radar VN (Diseño/Datos/Negocio/IA).  
4. **A11y/noise:** LG es denso; VN debe **ganar por claridad** (menos ruido cognitivo — ya en sobre-mí).  
5. **No** pretender retail CE; sí **empatía con producto físico + digital + servicio post-venta**.
